# ろくぶつけ（Unity Web版）

スマホのブラウザで遊べる「ろくぶつけ」の試作品です。

- 遊ぶ: https://rokubutsuke-game.pages.dev （Cloudflare Pages で自動公開）
- キャラ確認（仮キャラの動き）: https://rokubutsuke-game.pages.dev/chara/
- 学校グラウンド確認（コートを学校グラウンドにした版）: https://rokubutsuke-game.pages.dev/school/
- ステージ切り替え：タイトル画面の「通常ステージ／とある校庭」ボタン（PCはTキーでも可）。一人称版（?fp=1）でも同じ
- 中身: Unity 6.3 で書き出した Web ビルド（`index.html` / `Build/` / `TemplateData/`）

このリポジトリに push すると、Cloudflare Pages が自動で公開します。
